# Floating Camera — L30 Technology website (v2)

Modern, responsive, static landing page for Floating Camera. No build process or external dependencies.

## Preview
Open `index.html` in a browser. Or run `python -m http.server 8000` from this directory and open `http://localhost:8000`.

## Files
- `index.html`: full site (HTML, CSS, JavaScript; responsive design)
- `assets/floating-camera.png`: application icon
- `assets/l30-technology.png`: brand mark
- `assets/floating-camera-real-demo.webp`: illustrative product preview, as supplied

## Improvements
- Updated high-contrast modern design, responsive mobile menu, and more polished product showcase
- Working image enlargement dialog, FAQ accordion and anchor navigation
- Complete English, Portuguese and Spanish website translations; English default; language saved locally
- New how-it-works, use cases, product feature and FAQ sections
- Basic SEO metadata, accessibility labels, keyboard navigation and reduced-motion support
- No external trackers or libraries

## Publishing
Upload all files and the `assets` directory to a static host such as Cloudflare Pages or GitHub Pages. You may deploy to a dedicated subdomain to avoid overwriting an existing website.

## Important launch notes
- Trial and annual license buttons currently open an email draft; they are **not** functional installer downloads, checkout pages, or automated license issuance.
- Confirm license pricing, terms, installer safety and device policies before launch.
- The preview image is illustrative and should not be represented as an unmodified screenshot.
- No forms, analytics or backend are present. Only the language preference is saved locally in browser storage.
